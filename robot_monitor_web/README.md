# RM26 机器人监控网页

## 功能
- 监听指定 ROS2 话题并展示在线状态、频率、计数和消息预览
- `/image_raw` 图像采用手动刷新，避免持续高频网页解码
- 浅色简洁页面，适合局域网内多设备访问

## 启动
在工作区根目录执行：

```bash
./run_monitor_web.sh
```

启动后在浏览器访问：

```text
http://<机器人IP>:8088
```

例如：

```text
http://192.168.1.100:8088
```

## 资源占用优化点
- 前端状态轮询间隔为 2 秒
- 高频话题仅节流更新预览文本，降低 Python 侧序列化开销
- 图像只在按钮点击时请求下一帧并编码 JPEG
